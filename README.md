# 小紅書收藏夾管理工具 (MVP)

> 100% 本地運行:單檔 HTML + 油猴腳本,不部署、不請求外部服務,防火牆環境直接可用。

## 檔案

| 檔案 | 用途 |
|---|---|
| `xhs-favorites-manager.html` | 管理台:貼入 JSON → 解析 → 分類/搜尋/統計/匯出。**雙擊即開**,零依賴 |
| `xhs-favorites-exporter.user.js` | 油猴腳本:在小紅書收藏頁掃描已載入的卡片,存 LocalStorage,複製 JSON |

## 快速開始

### 1. 管理台(先開這個玩介面)

雙擊 `xhs-favorites-manager.html`,點右上角「**載入示範資料**」即可看到完整流程。

### 2. 匯入你的真實收藏

**方案 A — F12 抓包(最穩,完全不碰反爬):**
1. 瀏覽器登入小紅書網頁版 → 個人主頁 → 收藏分頁
2. 按 F12 → Network 頁籤 → 重新整理
3. 找到 `note/...` 相關的 XHR 請求(網址含 `api/sns/web/v1/note/`),點開 **Response**
4. 全選複製 JSON,貼進管理台「資料匯入」文字框 → **貼上即自動解析**(或按按鈕)

**方案 B — 油猴腳本(半自動):**
1. Tampermonkey → 新增腳本 → 貼上 `xhs-favorites-exporter.user.js` 全部內容 → 儲存
2. 回到小紅書收藏頁,往下滑加載越多越好(腳本只讀 DOM,不發請求)
3. 點右下角浮動面板「**① 掃描本頁**」→ 繼續滾動 → 再掃(累積去重)
4. 全部掃完後按「**② 複製 JSON**」→ 回管理台貼入

## 功能

- **解析**:自動辨識 4 種格式(官方 API 回應 `data.notes` / `data.note_list`、本工具匯出檔、裸陣列、含 JSON 的 cURL 字串),以 note_id 去重合併,重複匯入保留你已打的分類與備註
- **管理**:分類 chips(預設美食/旅遊/穿搭/知識,可增刪)、關鍵字搜尋、卡片/清單雙檢視、單筆備註
- **批次分類**:`分類 = 關鍵字1,關鍵字2` 規則,一鍵歸檔未分類筆記
- **統計**:總數/已分類/未分類/分類數 stat tiles + 單色條形圖(附表格視圖)
- **匯出**:JSON(可再匯入)、Markdown(可貼 Obsidian/Notion)、複製到剪貼簿
- 資料只存在瀏覽器 localStorage,主題自動跟隨系統深淺色

## 反爬測試筆記(供你後續實驗)

- 方案 A/B 都**不主動發請求**,所以不會觸發頻率限制;瓶頸是官方「滑動加載」每次只給 ~20 筆
- 想測頻率限制:在 F12 Console 手動重發該 XHR(原封帶 Cookie),觀察回應从 200 → 461 / 验证码 的閾值
- Cookie 失效表現:Response 變登入頁 HTML,解析器會提示「無法辨識」,即代表需重新登入
- 封面圖有防盜鏈(Referer 檢查),離開小紅書網域後載不出是正常的,管理台用 `no-referrer` 盡量救

## 已知限制

- 小紅書前端 class 名是編譯產物,油猴腳本用屬性選擇器 + `__INITIAL_STATE__` 備援,改版時可能要微調
- LocalStorage 上限約 5MB,腳本設 5000 筆保護,超過請先複製 JSON 再清除
